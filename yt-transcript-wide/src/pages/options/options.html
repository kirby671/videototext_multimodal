Settings for the transcript card on YouTube watch pages. To analyze a transcript from anywhere, open Analyze a transcript or select the text and right-click → “Clean & analyze this transcript”.

Add your API key to analyze with Claude

Getting, cleaning and saving transcripts works without a key. “Analyze with Claude”, trend reports and the company network need your own Anthropic API key (translating with Claude does too, when Chrome’s free translator can’t). It’s stored locally in this browser and only sent to Anthropic when you run one of them.

  1. Create a key at console.anthropic.com. You’ll need to add some credit to your Anthropic account; the card shows what each run costs.
  2. Paste it into Anthropic API key below.
  3. Click Test to check it works, then Save.
